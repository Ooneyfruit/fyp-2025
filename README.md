# fyp-2025

Final Year Project 2025

To run set up the necessary files for this project, run 'npm run setup' to download dependencies and log in to Firebase. Then use 'npm start' pack together the main.js, and then launch an instance of the project on localhost. Alternatively, use 'npm run deploy' or 'npm run deploy:branch' to deploy a version of the code to main or the branch page.
